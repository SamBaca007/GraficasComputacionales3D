Detailed Description

Clase que representa y administra un Buffer de Direct3D 11.

Facilita la creación, actualización y enlace (binding) de diferentes tipos de buffers (Vertex, Index, Constant) en el pipeline gráfico.

void Buffer::render ( DeviceContext & deviceContext,
unsigned int startSlot,
unsigned int numBuffers,
bool setPixelShader = false,
DXGI_FORMAT format = DXGI_FORMAT_UNKNOWN )

Enlaza el buffer al pipeline gráfico para el renderizado.

Enlaza el buffer al pipeline de Direct3D 11 basándose en su tipo (m_bindFlag).

Dependiendo del bindFlag interno, establecerá el buffer en la etapa correspondiente (IA para Vertex/Index Buffers, o VS/PS para Constant Buffers).

Parameters
deviceContextContexto del dispositivo (DeviceContext).
startSlotRanura (slot) inicial donde se enlazará el buffer.
numBuffersNúmero de buffers a enlazar.
setPixelShaderSi es true, y es un Constant Buffer, lo enlazará al Pixel Shader.
formatFormato DXGI usado (necesario principalmente para Index Buffers).

Llama a la función adecuada de la API (IASetVertexBuffers, VSSetConstantBuffers, PSSetConstantBuffers o IASetIndexBuffer) dependiendo del propósito de este buffer.

Parameters
deviceContextContexto del dispositivo utilizado para enlazar.
startSlotSlot inicial para el enlazado (útil para múltiples buffers).
numBuffersCantidad de buffers a enlazar (generalmente 1).
setPixelShaderDetermina si también se enlaza al Pixel Shader (sólo para Constant Buffers).
formatFormato de los datos, necesario al enlazar Index Buffers (ej. DXGI_FORMAT_R32_UINT).

Actualiza los datos del buffer enviando nueva información a la VRAM.

Actualiza dinámicamente el contenido del buffer en la VRAM.

Actúa como un wrapper de UpdateSubresource de Direct3D 11.

Parameters
deviceContextContexto del dispositivo usado para la actualización.
pDstResourceRecurso de destino (generalmente m_buffer).
DstSubresourceÍndice del subrecurso de destino.
pDstBoxCaja (Box) que define la porción a actualizar (puede ser nullptr).
pSrcDataPuntero a los datos fuente en RAM.
SrcRowPitchTamaño en bytes de una fila de datos.
SrcDepthPitchTamaño en bytes de un slice de profundidad.

Emplea UpdateSubresource del DeviceContext para transferir memoria de la RAM hacia la memoria gráfica de la GPU.

Parameters
deviceContextContexto del dispositivo responsable de la actualización.
pDstResourceRecurso destino (generalmente m_buffer, no se usa explícitamente en el interior porque usa m_buffer por defecto).
DstSubresourceÍndice del subrecurso a actualizar (usualmente 0).
pDstBoxCaja 3D opcional que define la porción a actualizar.
pSrcDataPuntero a la memoria fuente en la CPU.
SrcRowPitchTamaño en bytes de una fila (para texturas/2D).
SrcDepthPitchTamaño en bytes de un corte de profundidad (para 3D).
