Detailed Description

Clase final que gestiona el ciclo de vida central del motor 3D.

Actúa como la fachada principal para inicializar el contexto gráfico, renderizar los frames y limpiar los recursos. Su ciclo de vida está estrictamente controlado (no se puede copiar ni mover).

Inicializa el motor y su implementación subyacente.

Prepara el entorno gráfico DirectX 11, crea el Swap Chain, shaders, layout y búferes 3D.

true si el motor se inicializó correctamente, false si ocurrió un error crítico.

Configura los objetos fundamentales como el backbuffer, el depth/stencil buffer, compila los shaders e inicializa el modelo base (un cubo colorido rotando) cargando sus vértices e índices en memoria gráfica.

◆ Render()

void Engine::Render ( )
noexcept

Ejecuta las rutinas de dibujado para el frame actual.

Ejecuta el ciclo de renderizado de la GPU para el cuadro actual.

Coordina la limpieza del back buffer, el envío de comandos de dibujado a la GPU y la presentación (swap) en la pantalla.

Limpia el Render Target y el Depth Stencil, calcula las matrices de transformación 3D animadas según el tiempo transcurrido, actualiza el constant buffer y ejecuta las llamadas a la pipeline de pintado (DrawIndexed).

Apaga el motor y destruye los subsistemas activos.
