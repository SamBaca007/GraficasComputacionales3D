Detailed Description

Clase que encapsula el contexto del dispositivo (ID3D11DeviceContext) de Direct3D 11.

El DeviceContext es el responsable de emitir comandos de renderizado a la GPU, configurar el pipeline gráfico, enlazar recursos a las distintas etapas (shaders) y realizar las llamadas de dibujo (draw calls).
