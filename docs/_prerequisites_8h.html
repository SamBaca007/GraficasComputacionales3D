Detailed Description

Archivo de cabecera principal con las dependencias y la API base del motor.

Incluye las librerías fundamentales del sistema y expone las funciones principales del ciclo de vida del motor mediante enlaces C (extern "C") para evitar el name mangling, facilitando su uso como biblioteca dinámica (DLL).
