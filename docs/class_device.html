Detailed Description

Clase que encapsula el dispositivo de Direct3D 11 (ID3D11Device).

El Device actúa como la "fábrica" principal de recursos. Se encarga de alojar memoria en la tarjeta gráfica (VRAM) y crear objetos como buffers, texturas, shaders, vistas y estados, los cuales luego son utilizados por el DeviceContext.

Crea una vista de Render Target (RTV) para un recurso.

Crea una vista de destino de renderizado (Render Target View).

Permite que el pipeline pueda dibujar sobre un recurso (generalmente una textura 2D que actúa como el back buffer).

Parameters
pResourcePuntero al recurso base (ej. el buffer extraído del SwapChain).
pDescDescripción de la vista (puede ser nullptr para crear una vista predeterminada).
ppRTViewPuntero doble donde se almacenará el RTV creado.
Returns
HRESULT S_OK si se creó exitosamente, o un código de error de lo contrario.
Parameters
pResourcePuntero al recurso del cual se creará la vista (usualmente el back buffer).
pDescPuntero a la descripción de la vista (puede ser nullptr para valores por defecto).
ppRTViewPuntero doble donde se almacenará el objeto de vista creado.
Returns
HRESULT S_OK si se creó la vista exitosamente, o un código de error detallado en caso contrario.
