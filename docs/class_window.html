Detailed Description

Clase final que representa y gestiona la ventana principal del motor.

Esta clase maneja la interacción directa con la API de Win32 para la ventana. Está diseñada para no ser copiable ni heredable.

◆ ProcessMessages()

bool Window::ProcessMessages ( )
noexcept

Extrae y procesa los mensajes de la cola de mensajes de Windows.

Procesa de forma no bloqueante todos los mensajes pendientes en la cola de la ventana.

Este método debe llamarse en cada ciclo del bucle principal para mantener la ventana activa y responsiva.

Returns
true si los mensajes se procesaron con normalidad. false si se recibió WM_QUIT (solicitud de cierre).
true Si se procesaron los mensajes correctamente.
false Si se interceptó el mensaje WM_QUIT (indicando el cierre de la aplicación).
