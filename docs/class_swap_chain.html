Detailed Description

Clase que encapsula la funcionalidad del SwapChain (Cadena de intercambio) de DXGI.

El SwapChain gestiona el intercambio de buffers (back buffer y front buffer) para presentar la imagen renderizada en la ventana del sistema operativo sin desgarro de pantalla (tearing).

Inicializa el SwapChain configurando sus descriptores y vinculándolo a la ventana.

Configura e inicializa el SwapChain (Cadena de intercambio).

Parameters

Define las características del back buffer (tamaño, formato, tasa de refresco, MSAA), extrae las interfaces DXGI (Device, Adapter y Factory) a partir del dispositivo de Direct3D, y finalmente crea la cadena de intercambio vinculándola a la ventana proporcionada.
